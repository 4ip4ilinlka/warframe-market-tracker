# Warframe Market Tracker — описание программы

Дата: 2026-11-25

## Зачем

1. Следить за ценами на warframe.market удобнее, чем на самом сайте: нужные предметы в одном месте, цены обновляются сами.
2. Знать, что из своего инвентаря можно выставить на продажу и за сколько.

Успех — открыл страницу и сразу видишь: сколько сейчас стоят отслеживаемые предметы и какие вещи из инвентаря стоит продать в первую очередь.

## Что входит (цели)

- **Список отслеживания.** Добавляешь предмет поиском по названию (рус./англ.) — прайм-части, наборы, моды, аркейны, реликвии. По каждому видно:
  - минимальная цена продажи (продавцы онлайн / в игре);
  - максимальная цена покупки;
  - средняя/медианная цена сделок за 48 ч и объём сделок;
  - для модов — цена с учётом ранга (0 и максимальный);
  - мини-график цены за 48 ч;
  - изменение относительно прошлого обновления (↑/↓).
  Обновление автоматическое (по умолчанию раз в 5 минут), плюс кнопка «обновить».
- **Моды разлома.** Отслеживание по оружию: самые дешёвые лоты с выкупом (buyout) по выбранному оружию, с характеристиками и ценой. Фильтр по нужным характеристикам (например, «крит. шанс + крит. урон»). **Обновление каждые 10 секунд**; новые лоты подсвечиваются.
- **Выставление лотов.** Из программы можно выставить предмет на продажу (цена, количество, ранг), изменить цену, снять лот, увидеть свои активные лоты. Из «что продать» — кнопка «выставить» у каждой строки с подставленной ценой. Каждое действие — только по клику пользователя; никакого автоматического выставления и автоподстройки цен в цикле.
- **Уведомления Windows** (всплывающие, со звуком): «появился мод разлома по оружию X с нужными характеристиками дешевле N», «предмет из отслеживания подешевел ниже N / подорожал выше N». Только локальные уведомления — ничего не уходит в Telegram/Discord и другие сервисы.
- **Инвентарь.** Кнопка «загрузить инвентарь» при запущенной игре: программа сама получает данные сессии из процесса Warframe и скачивает инвентарь.
- **«Что продать».** Сопоставление инвентаря с ценами маркета. Таблица по убыванию общей стоимости: предмет, количество, цена за штуку, итого. Фильтры по типу (прайм-части, моды, аркейны, реликвии). Отдельно — моды разлома из инвентаря с оружием, характеристиками и ориентиром цены (медиана текущих лотов по этому оружию).
- **Интерфейс на русском**, тёмная тема (как сама игра).
- **Один `.exe`** — запускаешь, открывается вкладка браузера. Python и другие программы ставить не нужно.

## Что не входит (не цели)

- Уведомления на телефон / в Discord / Telegram (данные ушли бы во внешний сервис).
- Массовое или автоматическое выставление лотов, автоподстройка цен, авто-ответы на сообщения покупателей.
- Точная оценка стоимости модов разлома (это отдельная сложная задача) — только ориентир.
- Консольные платформы: только ПК.
- Изменение чего-либо в игре или аккаунте.

## Анти-цели (что сделает программу провалом, даже если она «работает»)

- Программа что-то **записывает** в игру или шлёт на серверы игры что-то кроме чтения инвентаря.
- Данные сессии (accountId, nonce), токен маркета или любые сведения о ПК уходят куда-либо, кроме серверов Warframe / warframe.market, или лежат на диске в открытом виде.
- Аккаунт игры или маркета получает бан из-за программы.
- Спам запросами на warframe.market до бана по IP.
- Медленно: открыл — и ждёшь минуту.

## Главное требование: приватность и защита от бана

Пользователь просит свести к минимуму два риска: утечку данных о его ПК и бан (в игре и на маркете). Это важнее удобства.

**Приватность**
- Программа обращается **только** к `api.warframe.market` и `api.warframe.com` (и картинкам с `warframe.market`). Никакой телеметрии, аналитики, автообновлений, сторонних CDN — все скрипты и стили страницы лежат внутри `.exe`.
- Локальный сервер слушает только `127.0.0.1` — с других устройств в сети его не видно.
- В запросах — обычный нейтральный User-Agent, никаких данных о системе (имя ПК, пользователя, железо).
- accountId/nonce игры — только в памяти, на диск не пишутся, в логи не попадают.
- Вход на маркет — **логином и паролем внутри программы** (решение пользователя). Пароль отправляется только на `api.warframe.market` по HTTPS, нигде не сохраняется и не логируется; после входа остаётся только токен. Если вход через API упрётся в капчу/2FA — запасной путь: вставить токен из браузера по инструкции.
- Токен входа на маркет хранится зашифрованным средствами Windows (DPAPI — расшифровать может только твоя учётная запись Windows). Кнопка «выйти» удаляет его.
- Логи без личных данных.
- Единственное, что неизбежно видят серверы маркета и игры, — твой IP, как и при обычном использовании сайта/игры.

**Защита от бана в игре**
- Память игры **только читается** (права `PROCESS_VM_READ` + `PROCESS_QUERY_LIMITED_INFORMATION`), никаких внедрений, хуков, записи, изменения файлов игры.
- Память читается **только по кнопке** «загрузить инвентарь», не постоянно в фоне.
- Запрос инвентаря — тот же, что делает сама игра; не чаще одного раза в 2 минуты (ограничение в программе).
- Функция инвентаря выключена, пока пользователь сам её не включит (с предупреждением о риске). Остальная программа от неё не зависит.
- Честно: риск не нулевой — чтение памяти формально против правил игры. Сведён к тому же уровню, что у AlecaFrame.

**Защита от бана на маркете**
- Общий лимит не выше 2 запросов в секунду (у маркета ~3), с паузой при ответе 429.
- Моды разлома: 1 запрос на оружие раз в 10 секунд; при нескольких оружиях запросы распределяются по времени, чтобы не превысить лимит. Если отслеживается много оружий, интервал автоматически растёт, и программа это показывает.
- Лоты создаются/меняются только по клику пользователя (это как пользоваться сайтом), без ботовского поведения.

## Ограничения

- **API warframe.market**: публичный, без ключа, лимит ~3 запроса в секунду. Нужна очередь запросов и кэш.
  - `GET https://api.warframe.market/v2/items` — все предметы; у каждого есть `gameRef` (внутреннее игровое имя) — по нему инвентарь сопоставляется с маркетом напрямую. Заголовок `Language: ru` даёт русские названия.
  - `GET /v2/orders/item/{slug}/top` — лучшие лоты продажи/покупки.
  - `GET /v1/items/{slug}/statistics` — статистика сделок за 48 ч / 90 дней.
  - `GET /v2/riven/weapons` — оружие для модов разлома (с `gameRef` и диспозицией).
  - Аукционы модов разлома: `GET /v1/auctions` отдаёт свежие лоты, **но `/v1/auctions/search?type=riven&weapon_url_name=…` сейчас возвращает пустой список** даже для оружия с активными лотами. Нужно найти рабочий способ поиска (посмотреть, какие запросы делает сам сайт). Запасной вариант, если не найдётся: периодически забирать ленту свежих лотов `/v1/auctions`, копить её в базе и фильтровать по оружию локально (покрытие хуже, но работает).
- **Инвентарь**: официального API нет. Способ — как у AlecaFrame / warframe-api-helper: найти в памяти процесса `Warframe.x64.exe` строку запроса с `accountId=<24 hex>` и `nonce=<число>`, затем `GET https://api.warframe.com/api/inventory.php?accountId=…&nonce=…`. Только чтение памяти, без записи. Формально нарушает правила игры — пользователь знает и согласен.
  - Работает только при запущенной игре и после входа в аккаунт.
  - Последний загруженный инвентарь сохраняется локально (без данных сессии), чтобы «что продать» работало и без игры.
- Windows 10/11, ПК.

## Варианты, которые рассматривали

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Python + страница в браузере** ✅ выбран | быстро писать и менять; удобные таблицы и графики в браузере; собирается в один `.exe` | интерфейс во вкладке браузера, а не в отдельном окне |
| C# / .NET (WPF) | родное окно Windows, удобная работа с памятью процесса | интерфейс делать дольше, менять сложнее |
| Electron (JS) | отдельное окно с веб-интерфейсом | ~150 МБ, для чтения памяти нужны нативные модули |

Выбор пользователя: страница в браузере, Python-сервер внутри, автоматическое получение инвентаря (вариант 1 из обсуждения).

## Устройство

```
 [Вкладка браузера: localhost:8777]
          │  HTTP/JSON
 [Локальный сервер (Python)]
   ├─ market: клиент warframe.market (очередь ≤3 req/s, кэш)
   ├─ inventory: поиск процесса → чтение памяти → inventory.php
   ├─ matcher: инвентарь ↔ предметы маркета по gameRef
   └─ storage: SQLite (список отслеживания, история цен, последний инвентарь)
```

- Сервер слушает только `127.0.0.1`.
- При первом запуске скачивает справочник предметов (`/v2/items` на ru и en), обновляет его раз в сутки.
- История цен копится локально при каждом обновлении — со временем можно смотреть дольше, чем 48 ч.

## Оставлено на усмотрение разработчика

- Конкретные библиотеки (веб-сервер, сборка в `.exe`, работа с памятью процесса).
- Точный алгоритм поиска accountId/nonce в памяти.
- Структура таблиц SQLite.
- Как именно сопоставлять составные случаи (чертежи vs. детали, ранги модов в инвентаре).

## Решения, которые я принял сам (можно поправить)

- Порт `8777`, автооткрытие вкладки при запуске.
- Обновление цен раз в 5 минут; учитываются только продавцы со статусом «в игре»/«онлайн».
- Цена для «что продать» = медиана сделок за 48 ч; если сделок нет — минимальная цена продажи онлайн.
- Предметы из инвентаря, которых нет на маркете (непродаваемые), скрываются.
- Показываются все продаваемые предметы, включая самые дешёвые (решение пользователя).
- Моды в инвентаре без ранга оцениваются по цене ранга 0, с максимальным рангом — по цене макс. ранга, промежуточные — по рангу 0.
