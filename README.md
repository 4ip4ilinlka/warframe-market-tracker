# WF Market Tracker

Программа для Windows, которая помогает торговать на [warframe.market](https://warframe.market): показывает, что из вашего инвентаря можно продать и за сколько, следит за ценами и модами разлома, выставляет лоты и присылает уведомления.

## Скачать и запустить

1. Откройте [последний релиз](https://github.com/4ip4ilinlka/warframe-market-tracker/releases/latest) и скачайте **WFMarketTracker.exe**.
2. Запустите его. Windows может показать «Система Windows защитила ваш компьютер» — программа не подписана сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Откроется вкладка браузера `http://127.0.0.1:8777` — это и есть программа. Окна у неё нет; чтобы закрыть, нажмите **«Выход»** справа вверху на странице.

Устанавливать ничего не нужно, Python не нужен. Работает на Windows 10/11.

## Первые шаги

1. **«Мои лоты»** — войдите на warframe.market (почта и пароль или токен из браузера — инструкция там же). Нужно, только если хотите выставлять лоты из программы.
2. **«Что продать»** → «Понимаю, включить» → запустите Warframe, войдите в аккаунт → **«Загрузить инвентарь»**. Цены подтянутся сами, самое ценное — первым.

## Что умеет

- **Что продать** — все ваши предметы с ценой и суммой, отметка того, что уже выставлено (значок магазина), фильтры по категориям и подкатегориям (прайм-варфреймы, оружие, моды по типам, реликвии по эрам…), сортировка, кнопка «Выставить». Моды разлома оцениваются по похожим лотам на маркете (те же плюсы, такой же по вредности минус).
- **Карточка предмета** — клик по любому предмету: график сделок за 48 часов и 90 дней, продавцы и покупатели онлайн, кнопки «Купить»/«Продать» копируют готовое сообщение для чата игры.
- **Мои лоты** — цена, количество, видимость, снятие лота прямо в программе.
- **Отслеживание** — цены выбранных предметов с графиком и стрелкой изменения.
- **Моды разлома** — самые дешёвые лоты по оружию и характеристикам, новые подсвечиваются.
- **Уведомления** — в углу экрана Windows: «цена упала ниже N», «медиана выше N», новый подходящий мод разлома.

Цены обновляются сами: всё — раз в час, выставленное на продажу и 50 самых ценных предметов — каждые 10 минут. Кнопка «Обновить цены…» позволяет выбрать, какие категории обновить сейчас.

## Приватность и риски

- Программа обращается только к `api.warframe.market`, `warframe.market` (картинки), `api.warframe.com` и `mobile.warframe.com`. Нет телеметрии, автообновлений и сторонних серверов. Страница доступна только с этого компьютера.
- Пароль маркета отправляется только на warframe.market и не сохраняется; токен входа хранится зашифрованным средствами Windows.
- Ваши данные лежат в `%LOCALAPPDATA%\WFMarketTracker\` и никуда не отправляются.
- **Инвентарь**: выключен по умолчанию. По кнопке программа *читает* (не изменяет) память процесса Warframe, чтобы взять данные текущей сессии, и один раз запрашивает инвентарь у серверов игры — так же работают AlecaFrame и похожие программы. Формально это нарушает правила игры: риск бана небольшой, но не нулевой. Используйте на своё усмотрение.

## Для разработчиков

```powershell
python -m venv C:\wfmt-venv
C:\wfmt-venv\Scripts\python.exe -m pip install -r requirements-dev.txt
C:\wfmt-venv\Scripts\python.exe -m pytest
.\build.ps1 -Venv C:\wfmt-venv
```

Готовый файл появится в `dist\WFMarketTracker.exe`. Окружение лучше держать по короткому пути — у Windows ограничение на длину пути.
